This is a rudimentary test repository for my summer project. The aim is to implement Monte Carlo on surfaces with a stress-free boundary. The current purpose is to reliably compute the geodesic curvature over the boundary, which I am currently trying and testing out in the notebook GeodesicCurvature.ipynb. I will keep updating this test repository as I work on setting the code straight. Once the pipeline is working, the end goal is to be able to integrate with MeMC and study the statistical mechanics of a solid ribbon twisted into a Mobius strip.
